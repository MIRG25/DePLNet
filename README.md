# DePLNet

## Project Description

Accurate segmentation of brain tumor subregions is important for neurosurgical planning. Semi-supervised learning (SSL) facilitates segmentation with limited annotations by leveraging unlabeled data. However, existing SSL methods remain susceptible to systematic pseudo-label bias, leading to substantial errors in small tumor subregions and inaccurate tumor boundary delineation. To address this issue, we propose the Debiased Pseudo-Labeling Network (DePLNet).
